# Конфижим для удобства

## 1 Где хранятся пользовательские и системные настройки подключения?
Пользовательские в папке .ssh в папке пользователя (~/.ssh). Системные в /etc/openssh.
## 2 Что за файл options?
(config?)
Конфигурационный файл с параметрами ssh.
## 3 Отредактируйте файл options так, чтобы можно было подключаться не вводя имя пользователя и порт
*(Отсюдова выполняю задания 2 и 7 - 10, используя локальную машинку, т. к. наши виртуалки закрыли. На ней тоже Alt, у которого из коробки openssh.)*
Файл ~/.ssh/config:
```bash
# OpenSSH client configuration file format is described in ssh_config(5) manual page.
Host maleha
        HostName 192.168.0.184
        Port 22
        User maleha
```
